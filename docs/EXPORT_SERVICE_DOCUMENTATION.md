# Export Service Documentation

## Overview
The `ExportService` is a generic, reusable utility for exporting data to Excel and PDF formats. It can be used across different modules in your application.

## Installation
The required dependencies are already installed:
- `exceljs` - For Excel exports
- `jspdf` - For PDF generation
- `jspdf-autotable` - For PDF tables

## Basic Usage

### Method 1: Direct Service Usage

```typescript
import { ExportService } from '@/utils/ExportService';

// Export to Excel
await ExportService.exportToExcel({
    filename: 'my-data',
    title: 'My Report',
    columns: [
        { header: 'ID', key: 'id', width: 10 },
        { header: 'Name', key: 'name', width: 20 },
        { header: 'Email', key: 'email', width: 25 }
    ],
    data: myDataArray,
    metadata: {
        'Generated By': 'John Doe',
        'Date': new Date().toLocaleDateString()
    }
});

// Export to PDF
ExportService.exportToPDF({
    filename: 'my-data',
    title: 'My Report',
    columns: [
        { header: 'ID', key: 'id' },
        { header: 'Name', key: 'name' },
        { header: 'Email', key: 'email' }
    ],
    data: myDataArray
});
```

## Configuration Options

### ExportConfig Interface

```typescript
interface ExportConfig {
    filename: string;        // Filename without extension
    sheetName?: string;      // Excel sheet name (default: 'Sheet1')
    title?: string;          // Title displayed at the top
    columns: ExportColumn[]; // Column definitions
    data: any[];            // Array of data objects
    metadata?: Record<string, any>; // Optional metadata to display
}
```

### ExportColumn Interface

```typescript
interface ExportColumn {
    header: string;  // Column header text
    key: string;     // Object property key (supports nested: 'user.name')
    width?: number;  // Column width (Excel: characters, PDF: mm)
}
```

```vue
<script setup lang="ts">
import { ref, computed } from 'vue';
import { useExport } from '@/composables/useExport';

const { exportToExcel, exportToPDF } = useExport();

// Sample data
const breeders = ref([
    { id: 1, name: 'Juan dela Cruz', region: 'Luzon', province: 'Laguna', municipality: 'Los Baños', commodity: 'Rice', status: 'Active' },
    { id: 2, name: 'Maria Santos', region: 'Visayas', province: 'Cebu', municipality: 'Cebu City', commodity: 'Corn', status: 'Active' },
    { id: 3, name: 'Pedro Reyes', region: 'Mindanao', province: 'Davao del Sur', municipality: 'Davao City', commodity: 'Banana', status: 'Inactive' }
]);

// Filter state

const selectedStatus = ref('');

// Filtered data
const filteredBreeders = computed(() => {
    return breeders.value.filter(breeder => {
        const matchRegion = !selectedRegion.value || breeder.region === selectedRegion.value;
        const matchStatus = !selectedStatus.value || breeder.status === selectedStatus.value;
        return matchRegion && matchStatus;
    });
});

// Export columns configuration
const exportColumns = [
    { header: 'ID', key: 'id', width: 8 },
    { header: 'Breeder Name', key: 'name', width: 25 },
    { header: 'Region', key: 'region', width: 15 },
    { header: 'Province', key: 'province', width: 20 },
    { header: 'Municipality', key: 'municipality', width: 20 },
    { header: 'Commodity', key: 'commodity', width: 15 },
    { header: 'Status', key: 'status', width: 12 }
];

// Export handlers
const handleExportExcel = async () => {
    await exportToExcel({
        filename: `breeders-export-${new Date().getTime()}`,
        sheetName: 'Breeders Data',
        title: 'Philippine Breeders Database',
        columns: exportColumns,
        data: filteredBreeders.value,
        metadata: {
            'Total Records': filteredBreeders.value.length,
            'Region Filter': selectedRegion.value || 'All',
            'Status Filter': selectedStatus.value || 'All',
            'Export Date': new Date().toLocaleString(),
            'Generated By': 'CBC BioMap System'
        }
    });
};

const handleExportPDF = () => {
    exportToPDF({
        filename: `breeders-export-${new Date().getTime()}`,
        title: 'Philippine Breeders Database',
        columns: exportColumns,
        data: filteredBreeders.value,
        metadata: {
            'Total Records': filteredBreeders.value.length,
            'Region Filter': selectedRegion.value || 'All',
            'Status Filter': selectedStatus.value || 'All'
        }
    });
};
</script>

<template>
    <div class="breeders-page">
        <!-- Filters -->
        <div class="filters mb-4">
            <select v-model="selectedRegion" class="form-select">
                <option value="">All Regions</option>
                <option value="Luzon">Luzon</option>
                <option value="Visayas">Visayas</option>
                <option value="Mindanao">Mindanao</option>
            </select>
            
            <select v-model="selectedStatus" class="form-select">
                <option value="">All Status</option>
                <option value="Active">Active</option>
                <option value="Inactive">Inactive</option>
            </select>
        </div>

        <!-- Export Buttons -->
        <div class="export-buttons mb-4">
            <button @click="handleExportExcel" class="btn btn-success me-2">
                <i class="bi bi-file-excel"></i> Export to Excel
            </button>
            <button @click="handleExportPDF" class="btn btn-danger">
                <i class="bi bi-file-pdf"></i> Export to PDF
            </button>
        </div>

        <!-- Data Table -->
        <table class="table">
            <thead>
                <tr>
                    <th>ID</th>
                    <th>Name</th>
                    <th>Region</th>
                    <th>Province</th>
                    <th>Municipality</th>
                    <th>Commodity</th>
```

## Tips

1. **Performance**: For large datasets (>10,000 rows), consider paginating or filtering data before export.

2. **Column Width**: 
   - Excel: Width is in characters (default: 15)
   - PDF: Width is in millimeters (auto-calculated if not specified)

3. **Nested Properties**: Use dot notation to access nested properties: `'user.profile.name'`

4. **File Naming**: Include timestamps in filenames to avoid overwriting: 
   ```typescript
   filename: `export-${new Date().getTime()}`
   ```

5. **Error Handling**: Always wrap export calls in try-catch blocks:
   ```typescript
   try {
       await exportToExcel(config);
       // Show success message
   } catch (error) {
       // Show error message to user
       console.error('Export failed:', error);
   }
   ```

## Troubleshooting

**Issue**: Export button not working
- Check browser console for errors
- Ensure data is properly loaded before export
- Verify column keys match your data object properties

**Issue**: Nested properties not showing
- Use dot notation: `'user.name'` not `'user[name]'`
- Ensure the nested property exists in all data objects

**Issue**: PDF/Excel file not downloading
- Check browser pop-up blocker settings
- Ensure you're calling the function in response to user action (not on page load)
