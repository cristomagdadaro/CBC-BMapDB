# Export Service - Quick Reference Guide

## Quick Start

### 1. Import the composable in your Vue component:
```typescript
import { useExport } from '@/composables/useExport';
const { exportToExcel, exportToPDF, exportToAll } = useExport();
```

### 2. Define your columns:
```typescript
const columns = [
    { header: 'ID', key: 'id', width: 10 },
    { header: 'Name', key: 'name', width: 25 },
    { header: 'Email', key: 'email', width: 30 }
];
```

### 3. Export your data:
```typescript
// Excel
await exportToExcel({
    filename: 'my-export',
    title: 'My Report',
    columns: columns,
    data: myData
});

// PDF
exportToPDF({
    filename: 'my-export',
    title: 'My Report',
    columns: columns,
    data: myData
});
```

## Common Use Cases

### Export Filtered Data
```typescript
const exportFiltered = async () => {
    const filtered = data.value.filter(item => item.status === 'active');
    await exportToExcel({
        filename: 'active-users',
        columns: columns,
        data: filtered,
        metadata: { 'Filter': 'Status: Active' }
    });
};
```

### Export with Metadata
```typescript
await exportToExcel({
    filename: 'report',
    columns: columns,
    data: data,
    metadata: {
        'Report Date': new Date().toLocaleDateString(),
        'Total Records': data.length,
        'Generated By': userName
    }
});
```

### Export Nested Properties
```typescript
const columns = [
    { header: 'User Name', key: 'user.name' },
    { header: 'User Email', key: 'user.email' },
    { header: 'City', key: 'address.city' }
];
```

## Button Templates

### Bootstrap Buttons
```vue
<button @click="exportToExcel(config)" class="btn btn-success">
    <i class="bi bi-file-excel"></i> Export Excel
</button>

<button @click="exportToPDF(config)" class="btn btn-danger">
    <i class="bi bi-file-pdf"></i> Export PDF
</button>
```

### With Loading State
```vue
<button 
    @click="handleExport" 
    :disabled="isExporting"
    class="btn btn-success"
>
    <span v-if="isExporting">Exporting...</span>
    <span v-else>Export Excel</span>
</button>
```
